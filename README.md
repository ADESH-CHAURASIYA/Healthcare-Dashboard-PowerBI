# Papollo Healthcare Hospital Dashboard (Power BI)

## 📊 Project Overview
This project presents an interactive Power BI dashboard for analyzing hospital data and monitoring key performance indicators.

## 🔧 Tools Used
- Power BI

## 📌 Key Features
- Patient admissions and discharge tracking
- Bed occupancy analysis
- Diagnosis-wise patient insights
- Doctor feedback analysis
- Billing and revenue performance

## 📈 Insights
- Identified trends in patient flow and hospital utilization
- Improved visibility of hospital KPIs through interactive visuals
